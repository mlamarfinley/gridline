# Matchup unit comparison

Place a two-team comparison below the game header and performance summary, above the existing player/overview tabs. Preserve the dark theme, player cards, sliders and league-wide ratings view.

Use the ratings contained in that matchup, not the latest league-wide team snapshots. Show an expandable transposed table of all existing unit ratings for the away and home teams, with same-unit rating gaps. Missing values remain unavailable.

Show three interacting-unit comparisons per offense: pass protection versus opponent pass rush, run blocking versus opponent run front, and receiver production versus opponent coverage. Sort by absolute gap within each offense. Gaps smaller than five rating points are described as closely matched. Explain likely football implications in one sentence; these are qualitative comparisons of unit indices, not fitted effects, score differences or probabilities. Label completed-game views as rebuilt pregame ratings.
