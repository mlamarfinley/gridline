# NFL snap-depth implementation plan

Goal: preserve every available play record, expose precise usage and situational metrics, and add a possession-based game-flow challenger without changing saved forecasts.

Architecture: retain the original nflverse compressed season file as the full event archive; derive explicitly typed snap/drive records and cutoff-filtered team/player profiles. A separate seeded drive-resampling model uses own offense, opposing defense and league history to generate possession/turnover/score timelines. It is experimental, not promoted by a retrospective result. Matchup pages show evidence/coverage and player usage; immutable snapshots archive the new challenger.

Constraints: NFL only; never feed target-game or later plays into forecasts. Missing charting is unavailable, not zero. Keep incidental production in team model while excluding incidental player picks. No claim to know all 22 players' routes from public PBP. Current charting gaps and archived source timestamps must be disclosed. Retain Week 6 and Week 7 frozen cohorts.

1. Add canonical snap loader to src/pbp.js, preserving source file, source time, complete event IDs, flags, players, clock, field, drive results, EPA/CPOE/xpass and penalties. Test parsing and numeric null handling.
2. Add src/snapAnalytics.js: deduplicate game/play IDs; cutoff by prior regular-season week and game date; build season/recent-three and down/distance/score/field splits. Exclude no-play/deleted/two-point/kneel/spike from competitive usage. Dropbacks include sacks and scrambles; target share denominator is identified targets, not attempts. Player/position shares include unknown-position coverage. Pressure is labeled sack/hit proxy; routes unavailable. Test exact denominators, missingness, scramble handling, leakage and duplicates.
3. Add src/driveModel.js: derive observed drives with clocks/field positions/outcomes and resample own offense/opposing defense/league drives. Alternate possession, apply turnovers and short fields, reset at halftime, output regulation minute leader probabilities and final score distribution. Keep defensive TDs/safeties and special teams explicit. Test deterministic outputs, conservation, boundaries and turnover/field-position effects. Document limitations of empirical drive sequences.
4. Integrate per-team and per-player analytics in src/matchup.js and clear evidence tables in public/app.js. Attach new drive challenger to gameScript; archive without rewriting existing records. Missing data must not break baseline predictions.
5. Add chronological replay command with cutoff assertions, market comparison and report artifact. Compare completed 2026 games with Week 6 separated; label reconstructed diagnostics. Run all tests, inspect UI and validate real source coverage. Review code, publish and verify deployment.
