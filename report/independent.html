How to use this report

Start with evidence, then rank. The hierarchy shows every measured category by default. Use the evidence filter to require 20 decisions and 10 games. Even those are small samples. Several stats from one player/game share the same underlying events.

No repeated model votes. Each of the 13 Week 6 games contributes its latest saved pregame run once. Both versions are scored on the archived experimental cohort. Stats without an archived experimental projection are not silently replaced with the main model.

No invented Week 5. The ledger contains no NFL Week 5 forecasts or backtests. Reconstructing it now would be a different experiment, not an original prediction.

What is excluded. Missing results, missing lines, pushes and a projection exactly equal to the line do not count as decided picks. No line means we can still measure projection error, but cannot grade an over/under selection.

Uncertainty. Intervals resample games with replacement (1,200 draws per category, 2,000 for hypothesis differences). They account for shared game outcomes, but not every repeated-player or week effect. Many categories are compared, so the top rank can be noisy. They are descriptive, not adjusted significance tests.

Dates and updates. This is an independent, self-contained snapshot. Rebuild it to incorporate Week 6 result corrections; another week requires selecting its own archived cohort. It makes no network requests and will not silently change. The source script can reproduce it from the ledger.

No profit claim. A correct side does not establish a profitable wager. This report does not calculate returns or account for each pick’s price.

Why obvious roles might not win. A clear role can help forecast volume, while the sportsbook line already reflects that role. Beating the line requires information beyond “this player usually does this.” This is a plausible explanation, not something these comparisons prove.
